# СтройНорм РФ

Telegram-бот для поиска по строительным СП и ГОСТам РФ и подготовки ответов с цитатами на документ, пункт и страницу.

## Возможности

- поиск по загруженным PDF/TXT/MD документам;
- ответы только по найденным фрагментам;
- ссылки на документ, пункт и страницу, когда они присутствуют в базе;
- предупреждение о необходимости проверки актуальной официальной редакции;
- webhook-режим для Render и polling-режим для локальной разработки.

## Переменные окружения

- `TELEGRAM_BOT_TOKEN` — токен от BotFather;
- `OPENAI_API_KEY` — ключ OpenAI API;
- `OPENAI_MODEL` — модель, по умолчанию `gpt-4.1-mini`;
- `PUBLIC_URL` — публичный адрес Render, например `https://stroynorm-bot.onrender.com`;
- `WEBHOOK_SECRET` — произвольная длинная случайная строка;
- `ADMIN_TELEGRAM_ID` — необязательный Telegram ID администратора.

## Загрузка нормативов

Поместите легально полученные документы в `data/documents/`, затем выполните:

```bash
python -m scripts.ingest data/documents
```

Индекс будет создан в `data/stroynorm.db`. PDF должен содержать текстовый слой; для сканов предварительно требуется OCR.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.main
```

## Важно

Бот является справочным инструментом. Перед проектированием и строительством необходимо проверять статус и текст документа в официальном источнике.
